# 📝 Project 05: Dynamic Form Builder

An interactive form design canvas allowing users to pick fields (Text, Email, Number, Textarea) from a palette, customize labels inline, delete fields, and export the live form schema to JSON.

---

### Features
- Element palette generating field rows dynamically from template dictionaries.
- Inline editable field labels.
- Delegated field removal with empty-state toggle.
- Real-time serialization of canvas DOM state into clean JSON schema definitions.

### How to Run
Open [`index.html`](index.html) in your browser.
