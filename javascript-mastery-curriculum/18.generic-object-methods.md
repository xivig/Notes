# ⚡ Generic Object Methods: The Complete Reference Manual (ES6 – ES2024+)

The JavaScript `Object` constructor provides a robust suite of static methods for object creation, property introspection, prototype manipulation, descriptors, immutability, and data grouping.

## 1. Object.keys(obj)

Returns an array of strings representing all enumerable, string-keyed own properties of an object.

```javascript
const pastaTypes = {
  capellini: "angel hair",
  fettuccine: "flat ribbon-shaped",
  fusilli: "spiral-shaped",
  penne: "tube-shaped hollow"
};

const keys = Object.keys(pastaTypes);
console.log(keys);
// ['capellini', 'fettuccine', 'fusilli', 'penne']
```

> **Key Takeaway**: Does not traverse prototype chains. Does not include Symbol keys or non-enumerable properties.

---

## 2. Object.values(obj)

Returns an array of the values of the object's enumerable own properties, matching the order provided by `for...in`.

```javascript
const pastaTypes = {
  capellini: "angel hair",
  fettuccine: "flat ribbon-shaped",
  fusilli: "spiral-shaped",
  penne: "tube-shaped hollow"
};

const values = Object.values(pastaTypes);
console.log(values);
// ['angel hair', 'flat ribbon-shaped', 'spiral-shaped', 'tube-shaped hollow']
```

---

## 3. Object.entries(obj)

Returns an array of a given object's own enumerable string-keyed property `[key, value]` pairs.

```javascript
const product = {
  id: 101,
  name: "Mechanical Keyboard",
  price: 120
};

for (const [key, val] of Object.entries(product)) {
  console.log(`${key} => ${val}`);
}
// id => 101
// name => Mechanical Keyboard
// price => 120
```

---

## 4. Object.fromEntries(iterable)

Transforms a list of key-value pairs (such as from `Object.entries()`, `Map`, or arrays) back into an Object.

```javascript
// Example A: Filtering an object's properties
const prices = { laptop: 1200, mouse: 25, monitor: 350, cable: 15 };

const affordableOnly = Object.fromEntries(
  Object.entries(prices).filter(([_, price]) => price < 100)
);
console.log(affordableOnly);
// { mouse: 25, cable: 15 }

// Example B: Converting a Map to an Object
const userMap = new Map([['admin', 'Ada'], ['editor', 'Grace']]);
const userObj = Object.fromEntries(userMap);
console.log(userObj);
// { admin: 'Ada', editor: 'Grace' }
```

## 5. Object.assign(target, ...sources)

Copies all enumerable own properties from one or more source objects to a target object, returning the target object.

```javascript
const defaults = { theme: 'light', showSidebar: true, timeout: 3000 };
const userConfig = { theme: 'dark', timeout: 5000 };

// Merging into a new object:
const finalConfig = Object.assign({}, defaults, userConfig);
console.log(finalConfig);
// { theme: 'dark', showSidebar: true, timeout: 5000 }

// WARNING: Object.assign() performs SHALLOW copying!
const original = { user: { name: 'Alice' } };
const clone = Object.assign({}, original);
clone.user.name = 'Bob';
console.log(original.user.name); // 'Bob' (Mutated because inner object was shared!)
```

> **Modern Alternative**: Use spread `{ ...defaults, ...userConfig }` for shallow merges, or `structuredClone(obj)` for deep copies.

## 6. Object.create(proto, [descriptors])

Creates a new object using an existing object as the prototype of the newly created object.

```javascript
const animalPrototype = {
  isAlive: true,
  makeSound() {
    console.log(`${this.name} makes a generic sound.`);
  }
};

// Create a dog inheriting from animalPrototype:
const dog = Object.create(animalPrototype, {
  name: {
    value: 'Rex',
    writable: true,
    enumerable: true,
    configurable: true
  }
});

dog.makeSound(); // 'Rex makes a generic sound.'
console.log(dog.isAlive); // true (inherited from animalPrototype)
console.log(Object.getPrototypeOf(dog) === animalPrototype); // true

// PURE DICTIONARY PATTERN: Object with NO prototype:
const pureMap = Object.create(null);
// pureMap has no toString, no hasOwnProperty, completely safe from prototype pollution!
```

## 7. Object.defineProperty(obj, prop, descriptor)

Defines a new property directly on an object, or modifies an existing property, and returns the object.

A property descriptor can be **Data** or **Accessor**:

| Descriptor Key | Default Value | Description |
|:---|:---:|:---|
| `value` | `undefined` | The value associated with the property. |
| `writable` | `false` | `true` if and only if the value may be changed. |
| `enumerable` | `false` | `true` if and only if this property shows up in `for...in` and `Object.keys()`. |
| `configurable` | `false` | `true` if property type can be changed and property can be deleted. |
| `get` | `undefined` | A function which serves as a getter for the property. |
| `set` | `undefined` | A function which serves as a setter for the property. |

```javascript
const user = {};

Object.defineProperty(user, 'id', {
  value: 42,
  writable: false,      // Read-only!
  enumerable: true,     // Visible in Object.keys()
  configurable: false   // Cannot be deleted or reconfigured
});

console.log(user.id); // 42
user.id = 99;         // Fails silently (or throws TypeError in strict mode)
console.log(user.id); // 42 (Unchanged!)

delete user.id;       // Fails silently (or throws in strict mode)
console.log(user.id); // 42 (Still intact!)
```

## 8. Object.defineProperties(obj, descriptors)

Defines multiple properties simultaneously using an object of descriptors.

```javascript
const account = {};

Object.defineProperties(account, {
  accountNumber: {
    value: 'ACC-88391',
    writable: false,
    enumerable: true
  },
  balance: {
    value: 1500,
    writable: true,
    enumerable: true
  }
});

console.log(account.accountNumber, account.balance); // ACC-88391 1500
```

## 9. Object.getOwnPropertyDescriptor(obj, prop)

Returns an object describing the configuration of a specific own property on a given object.

```javascript
const car = { make: 'Toyota' };

const desc = Object.getOwnPropertyDescriptor(car, 'make');
console.log(desc);
// {
//   value: 'Toyota',
//   writable: true,
//   enumerable: true,
//   configurable: true
// }
```

## 10. Object.getOwnPropertyDescriptors(obj)

Returns all own property descriptors of a given object.

> **Crucial Use Case**: `Object.assign()` copies property values directly, which triggers getters and converts them into static values! `Object.getOwnPropertyDescriptors()` allows accurately cloning objects containing getters and setters:

```javascript
const temperatureTracker = {
  celsius: 25,
  get fahrenheit() {
    return (this.celsius * 9) / 5 + 32;
  }
};

// INCORRECT COPY (Collapses getter to static value):
const shallowCopy = Object.assign({}, temperatureTracker);
console.log(Object.getOwnPropertyDescriptor(shallowCopy, 'fahrenheit').get); // undefined!

// CORRECT ACCURATE CLONE (Preserves getter function):
const accurateClone = Object.create(
  Object.getPrototypeOf(temperatureTracker),
  Object.getOwnPropertyDescriptors(temperatureTracker)
);

console.log(typeof Object.getOwnPropertyDescriptor(accurateClone, 'fahrenheit').get); // 'function'
```

## 11. Object.freeze(obj) & Object.isFrozen(obj)

Freezes an object:
* Prevents adding new properties.
* Prevents removing existing properties.
* Prevents changing enumerability, configurability, or writability.
* Prevents values of existing properties from being changed.

```javascript
const config = { apiEndpoint: 'https://api.xivig.org' };

Object.freeze(config);
console.log(Object.isFrozen(config)); // true

config.apiEndpoint = 'https://malicious.org'; // Ignored!
config.newKey = 'test';                       // Ignored!
delete config.apiEndpoint;                   // Ignored!

console.log(config); // { apiEndpoint: 'https://api.xivig.org' }
```

> **Deep Freeze Notice**: `Object.freeze()` is **shallow**. Nested objects inside a frozen object can still be modified unless recursively frozen!

## 12. Object.seal(obj) & Object.isSealed(obj)

Seals an object:
* Prevents adding new properties.
* Prevents deleting existing properties.
* Marks all existing properties as `configurable: false`.
* **Properties that are writable remain writable!** You can still update existing values.

```javascript
const session = { token: 'xyz_123', retries: 0 };

Object.seal(session);
console.log(Object.isSealed(session)); // true

// Allowed (updating existing properties):
session.retries = 1;
console.log(session.retries); // 1

// Disallowed (adding new properties or deleting):
session.expiry = 3600; // Fails!
delete session.token;  // Fails!
console.log(session);  // { token: 'xyz_123', retries: 1 }
```

---

## 13. Object.preventExtensions(obj) & Object.isExtensible(obj)

Prevents new properties from ever being added to an object (i.e. prevents future extensions).
* Unlike `seal()` and `freeze()`, existing properties can still be **deleted** or **reconfigured**.

```javascript
const point = { x: 10, y: 20 };

Object.preventExtensions(point);
console.log(Object.isExtensible(point)); // false

point.z = 30; // Disallowed!
console.log(point.z); // undefined

delete point.x; // Allowed!
console.log(point); // { y: 20 }
```

## 14. Object.hasOwn(obj, prop) (ES2022)

Returns `true` if the specified object has the indicated property as its own property. If the property is inherited, or does not exist, the method returns `false`.

```javascript
const user = { name: 'Alice' };

console.log(Object.hasOwn(user, 'name')); // true
console.log(Object.hasOwn(user, 'toString')); // false (inherited from Object.prototype!)

// WHY IT REPLACES obj.hasOwnProperty():
// 1. Works with Object.create(null) which has no prototype:
const noProto = Object.create(null);
noProto.active = true;
// noProto.hasOwnProperty('active'); // Throws TypeError!
console.log(Object.hasOwn(noProto, 'active')); // true (Works safely!)

// 2. Safe against malicious property shadowing:
const shadowed = { hasOwnProperty: () => false, valid: true };
console.log(shadowed.hasOwnProperty('valid')); // false (Defective!)
console.log(Object.hasOwn(shadowed, 'valid')); // true (Accurate!)
```

## 15. Object.is(value1, value2)

Determines whether two values are the same value.

Unlike the strict equality operator (`===`), `Object.is()` correctly handles two critical mathematical edge cases:

```javascript
// Edge Case 1: NaN equality
console.log(NaN === NaN);            // false ⚠️
console.log(Object.is(NaN, NaN));    // true  ✅

// Edge Case 2: Positive vs Negative Zero
console.log(+0 === -0);              // true  ⚠️
console.log(Object.is(+0, -0));      // false ✅
```

## 16. Object.getPrototypeOf() and setPrototypeOf()

Inspects and updates an object's internal `[[Prototype]]`.

```javascript
const parent = { role: 'parent', greet() { return 'Hello!'; } };
const child = Object.create(parent);

// Getting prototype:
console.log(Object.getPrototypeOf(child) === parent); // true

// Setting prototype dynamically:
const newParent = { role: 'new_parent' };
Object.setPrototypeOf(child, newParent);
console.log(child.role); // 'new_parent'
```

> **Performance Warning**: Mutating `[[Prototype]]` with `Object.setPrototypeOf()` severely disrupts JavaScript engine V8 optimization (Inline Caches). Always prefer creating objects with the desired prototype via `Object.create()`.

## 17. Object.getOwnPropertyNames(obj)

Returns an array of all string properties (including non-enumerable properties, but excluding Symbols) found directly on `obj`.

```javascript
const arr = ['a', 'b', 'c'];

// Object.keys only returns enumerable indices:
console.log(Object.keys(arr)); // ['0', '1', '2']

// Object.getOwnPropertyNames includes non-enumerable properties like 'length':
console.log(Object.getOwnPropertyNames(arr)); // ['0', '1', '2', 'length']
```

---

## 18. Object.getOwnPropertySymbols(obj)

Returns an array of all Symbol properties found directly on an object.

```javascript
const idSymbol = Symbol('id');
const authSymbol = Symbol('auth');

const secureEntity = {
  name: 'Gateway',
  [idSymbol]: 'gw_9921',
  [authSymbol]: 'token_secure'
};

// Symbol properties are invisible to Object.keys():
console.log(Object.keys(secureEntity)); // ['name']

// Retrieve all symbols:
const symbols = Object.getOwnPropertySymbols(secureEntity);
console.log(symbols.map(s => secureEntity[s])); // ['gw_9921', 'token_secure']

// Retrieve EVERYTHING (Strings + Symbols) via Reflect.ownKeys:
console.log(Reflect.ownKeys(secureEntity)); // ['name', Symbol(id), Symbol(auth)]
```

## 19. Object.groupBy(items, callbackFn) (ES2024)

Groups elements of an iterable (such as an Array) according to string keys returned by a callback function. The returned object has a `null` prototype, ensuring no collisions with standard Object prototype methods.

```javascript
const inventory = [
  { name: 'Apples', category: 'Produce', quantity: 10 },
  { name: 'Bananas', category: 'Produce', quantity: 0 },
  { name: 'Steak', category: 'Meat', quantity: 5 },
  { name: 'Chicken', category: 'Meat', quantity: 0 }
];

// Group by category:
const byCategory = Object.groupBy(inventory, item => item.category);
console.log(byCategory.Produce.map(i => i.name));
// ['Apples', 'Bananas']

// Group by custom stock status logic:
const byStock = Object.groupBy(inventory, item => item.quantity > 0 ? 'inStock' : 'restock');
console.log(byStock.inStock.map(i => i.name));
// ['Apples', 'Steak']
```

## 🔒 Immutability Comparison Matrix

| Operation | `Object.preventExtensions()` | `Object.seal()` | `Object.freeze()` |
|:---|:---:|:---:|:---:|
| Can add new properties? | ❌ No | ❌ No | ❌ No |
| Can delete existing properties? | ✅ Yes | ❌ No | ❌ No |
| Can modify existing values? | ✅ Yes | ✅ **Yes** | ❌ **No** |
| Changes property attributes? | ❌ No | ✅ Sets `configurable: false` | ✅ Sets `configurable: false`, `writable: false` |
| Deep or Shallow? | Shallow | Shallow | Shallow |
| Inspection method | `Object.isExtensible()` | `Object.isSealed()` | `Object.isFrozen()` |
