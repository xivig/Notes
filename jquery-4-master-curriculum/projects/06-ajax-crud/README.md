# ⚡ Project 06: Full AJAX CRUD Application

An end-to-end task manager performing Create, Read, Update, Delete (CRUD) operations against a real-world REST API using jQuery 4.0.

---

### Features
- **Read**: Asynchronously loads records via `GET /todos`.
- **Create**: Submits JSON payloads via `POST /todos` and prepends new items to the DOM.
- **Update**: Toggles completion states via partial update `PATCH /todos/:id`.
- **Delete**: Removes items via `DELETE /todos/:id` with fade-out animations.
- Real-time network sync status indicators.

### How to Run
Open [`index.html`](index.html) in your browser.
