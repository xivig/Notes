02 — MACOS SYSTEM

macOS Developer Setup & Homebrew

macOS comes with Apple Command Line Tools and default BSD utilities. Setting up modern GNU coreutils and Homebrew transforms macOS into an elite workstation.

INSTALL HOMEBREW & ESSENTIAL TOOLS 
# Install Homebrew Package Manager
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Install modern CLI essentials
brew install git coreutils zsh jq ripgrep

Apple Silicon (M1/M2/M3/M4) Architecture Paths

On Apple Silicon, Homebrew installs under /opt/homebrew instead of Intel's /usr/local. Ensure your ~/.zprofile initializes Homebrew:

ZSH SHELL PROFILE CONFIGURATION 
# Add to ~/.zprofile (or ~/.zshrc)
eval "$(/opt/homebrew/bin/brew shellenv)"
03 — CROSS-PLATFORM

macOS (BSD) vs. Linux (GNU) Quirks

Key differences that trip up developers switching between Mac laptops and Linux servers:

In-place Sed editingmacOS: sed -i '' 's/a/b/g' file | Linux: sed -i 's/a/b/g' file
Copy to system clipboardmacOS: pbcopy < file.txt | Linux: xclip -sel clip < file.txt
Paste from clipboardmacOS: pbpaste > file.txt | Linux: xclip -out -sel clip > file.txt
Open file/URL in default appmacOS: open index.html | Linux: xdg-open index.html
Get file size in bytesmacOS: stat -f%z file.txt | Linux: stat -c%s file.txt
Global .DS_Store Immunity

Prevent macOS Finder indexing files from cluttering any Git repository on your machine: echo ".DS_Store" >> ~/.gitignore_global && git config --global core.excludesfile ~/.gitignore_global

04 — VERSION CONTROL

Git Fundamentals & Global Setup

A pristine Git configuration ensures correct commit authorship, standard branch nomenclature, and normalized cross-platform line endings.

RECOMMENDED GLOBAL CONFIGURATION 
# Configure identity
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"

# Set modern default branch name
git config --global init.defaultBranch main

# Set terminal editor
git config --global core.editor "vim"

Line Ending Normalization (`core.autocrlf`)

Prevent Git from registering entire files as modified due to Windows CRLF vs macOS/Linux LF:

# On Windows:
git config --global core.autocrlf true

# On macOS and Linux:
git config --global core.autocrlf input

Authentication: Ed25519 SSH Keys

Generate a high-security, compact cryptographic key for password-less GitHub communication:

ssh-keygen -t ed25519 -C "your.email@example.com"
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519
ssh -T git@github.com

Everyday Workflow & File Tracking

Understanding the three architectural states of Git: Working Directory, Staging Area (Index), and Permanent Repository (HEAD).

Fixing the "Already Tracked" .gitignore Problem

If files like node_modules/, .env, or build logs were committed before being added to .gitignore, Git keeps tracking them. Untrack them safely without deleting local files:

UNTRACK CACHED FILES 
# Remove a directory from Git index while keeping local files on disk
git rm -r --cached node_modules/
git rm --cached .env

# Re-index entire project based on .gitignore
git rm -r --cached .
git add .
git commit -m "chore: stop tracking files specified in .gitignore"

07 — EMERGENCY FIXES

Git Troubleshooting & Disaster Recovery

1. The Rejected Push Error

Occurs when remote origin/main contains commits you lack locally:

# Safe resolution sequence:
git stash push -m "temp before pull"
git pull --rebase origin main
git stash pop
git push origin main

2. Time Travel & Recovery with `git reflog`

If you ran git reset --hard by mistake or deleted a branch: Git does not delete commits immediately. `reflog` tracks every pointer movement for 90 days:

RECOVER DELETED COMMITS 
# View complete movement of HEAD
git reflog
# Output:
# 8f9e0d1 HEAD@{0}: reset: moving to HEAD~1
# 3c2b1a0 HEAD@{1}: commit: valuable feature implementation

# Recover back to HEAD@{1}:
git reset --hard 3c2b1a0
# Or branch from it:
git switch -c recovered-work 3c2b1a0
Avoid Naked Force Pushing

Never run git push -f on shared branches. Always use git push --force-with-lease so the push will fail if a teammate pushed commits you haven't fetched yet.

09 — CORE UNIX

Unix & Linux Filesystem & Permissions

In Unix, everything is a file. Filesystem permissions are divided into User (u), Group (g), and Others (o).

Standard script executable permissionchmod 755 script.sh # rwxr-xr-x
Standard web document permissionchmod 644 index.html # rw-r--r--
Strict private key permissionchmod 600 ~/.ssh/id_ed25519
Secure SSH folderchmod 700 ~/.ssh
Recursive ownership updatesudo chown -R www-data:www-data /var/www

Power File Searching with `find`

# Find files by name ignoring case
find /var/www -iname "*.php"

# Find files larger than 50 Megabytes
find /var/log -type f -size +50M

# Find and execute command on matches safely in batches:
find . -type f -name "*.tmp" -delete
find . -type d -exec chmod 755 {} +
find . -type f -exec chmod 644 {} +

14 — PRODUCTION ENGINEERING

All-in-One Rigorous Shell Scripting Masterclass

The definitive 12-step architecture required for bulletproof, enterprise-ready automation software.

🛡️

Strict Mode

set -euo pipefail and IFS=$'\n\t' prevents silent failures, undefined variable crashes, and word-splitting bugs.

🧹

Atomic Traps

trap cleanup EXIT INT TERM guarantees temporary files, sockets, and lockfiles are purged even on abort.

⚡

Parameter Expansion

Execute substring slicing, default assignments, and pattern stripping directly in C without slow subshells.

PRODUCTION-READY CLI AUTOMATION TEMPLATE 
#!/usr/bin/env bash
# Unofficial Bash Strict Mode
set -euo pipefail
IFS=$'\n\t'

readonly SCRIPT_NAME="$(basename "$0")"
TEMP_DIR="$(mktemp -d)"

# Guaranteed atomic cleanup on ANY exit or termination signal
cleanup() {
  local exit_code=$?
  rm -rf "$TEMP_DIR"
  exit "$exit_code"
}
trap cleanup EXIT INT TERM

log() {
  echo "[$(date +'%Y-%m-%d %H:%M:%S')] $*"
}

# Parse CLI options cleanly with getopts
while getopts ":e:h" opt; do
  case "$opt" in
    e) ENV="$OPTARG" ;;
    h) echo "Usage: $SCRIPT_NAME -e <env>"; exit 0 ;;
    *) echo "Invalid option"; exit 1 ;;
  esac
done

log "Executing automation in atomic workspace: $TEMP_DIR"

Error out if unset${API_KEY:?Error: API_KEY must be defined}
Strip file extension (.tar.gz)${filename%.*} # production_app.tar
Extract extension only${filename##*.} # gz
Search & replace all occurrences${text//old/new}

15 — WEB STANDARDS

HTML5 Foundations & Document Architecture

A modern HTML5 document pairs semantic markup with critical `` metadata, responsive viewport scaling, and non-blocking script loading.

MODERN HTML5 BOILERPLATE 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="description" content="Production-ready web platform.">
  <title>Professional Web Application</title>
  <link rel="stylesheet" href="css/style.css">
  <script defer src="js/main.js"></script>
</head>
<body>
  <header><h1>Hello World</h1></header>
</body>
</html>
🏷️

UTF-8 Charset

Must be inside the first 1024 bytes of the document to properly decode international characters.

📱

Responsive Viewport

width=device-width, initial-scale=1.0 prevents mobile browsers from downscaling to desktop widths.

⚡

Script Defer

Downloads JavaScript in the background without blocking the HTML parser; executes after DOM is ready.

Heading Hierarchy Rule

Never skip heading levels (e.g., jumping from <h2> directly to <h4>). Screen readers rely on sequential headings to build a navigable table of contents.
