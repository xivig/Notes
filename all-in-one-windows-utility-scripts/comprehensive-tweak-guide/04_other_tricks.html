Chapter 4

Special Windows 11 Utilities & Lists

In this final chapter, we cover built-in admin activation, recursive directory listing tools, Adobe update blocks, CPU description modifications, Javascript password revealers, and lists of diagnostic Run commands/Shortcuts.

1. Activating Built-in Administrator Account

Windows 11 includes a hidden, built-in Administrator account that is inactive by default. This account bypasses typical User Account Control (UAC) prompts. You can activate it using a command console block running with administrative rights.

enable_admin.bat 
@echo off
net user Administrator /active:yes

2. Generating Recursive Directory Lists

To audit file folders, you can run a batch script to crawl a directory recursively and print all file paths to a text document.

file_lister.bat 
@echo off
chcp 65001 >nul
dir /b /s "%~dp0" > "%~dp0file_list.txt"

3. Disabling Adobe Acrobat / Reader Auto-Update Manager

You can block unified 64-bit Adobe Acrobat DC and Acrobat Reader DC from checking for updates in the background by setting the DWORD bUpdater to 0 under FeatureLockDown policies.

disable_adobe_updater.reg 
Windows Registry Editor Version 5.00

[HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Adobe\Adobe Acrobat\DC\FeatureLockDown]
"bUpdater"=dword:00000000

[HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Adobe\Acrobat Reader\DC\FeatureLockDown]
"bUpdater"=dword:00000000

4. Spoofing Processor Descriptions

Windows reads CPU details directly from the registry at boot time. By modifying the string key ProcessorNameString, you can customize the CPU description shown in System Properties.

spoof_cpu.reg 
Windows Registry Editor Version 5.00

[HKEY_LOCAL_MACHINE\HARDWARE\DESCRIPTION\System\CentralProcessor\0]
"ProcessorNameString"="Intel Core i9-14900KS @ 6.20GHz"

5. JavaScript Page Password Revealer

This simple JavaScript bookmarklet code changes any input fields on a webpage that have type="password" to type="text", instantly showing hidden password values.

password_revealer.js 
javascript:(function(){var el=document.getElementsByTagName('input');for(var i=0;i<el.length;i++){if(el[i].type=='password'){el[i].type='text';}}})();
