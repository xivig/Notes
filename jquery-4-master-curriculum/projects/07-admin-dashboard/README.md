# 📈 Project 07: Admin Analytics Dashboard

A modern executive metrics dashboard featuring animated number tickers, period toggles (Today, 7 Days, 30 Days), and live activity streams.

---

### Features
- KPI card grid showcasing Gross Revenue, Active Users, and Conversion Rates.
- Animated numeric ticker transitions using dummy JavaScript objects interpolated via jQuery's `.animate()` step callbacks.
- Interactive time-horizon filter switching (`today`, `week`, `month`).
- Real-time order stream simulation.

### How to Run
Open [`index.html`](index.html) in your browser.
