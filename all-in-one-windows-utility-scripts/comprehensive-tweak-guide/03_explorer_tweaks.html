Chapter 3

Windows Explorer & Shell Customizations

Configure local desktop environments by hiding specific directories, locking/disabling the Run dialog, generating desktop control links, and creating toggle items natively in Windows 11.

1. Hiding / Locking Folders via CLSID Renaming

Windows explorer routes folders named with specific CLSID suffixes (UUIDs) directly to those system apps. By renaming a folder named "Private" to Private.{21EC2020-3AEA-1069-A2DD-08002B30309D}, Windows 11 changes its icon to the Control Panel, blocking access to its internal contents.

lock_folder.bat 
@echo off
ren "Private" "Private.{21EC2020-3AEA-1069-A2DD-08002B30309D}"
attrib +h +s "Private.{21EC2020-3AEA-1069-A2DD-08002B30309D}"

2. Disabling the Run Command Box Policy

To restrict users from entering commands directly, you can disable the Run dialog. Writing a DWORD named NoRun set to 1 in Explorer policies locks the Win+R window and hides the Run option from the Start menu.

disable_run_box.reg 
Windows Registry Editor Version 5.00

; Disable Run command box (Win+R and Start menu Run Option) in Windows 11
[HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Policies\Explorer]
"NoRun"=dword:00000001

3. Creating Power Control Desktop Shortcuts

You can create quick buttons on the desktop to Restart or Shutdown. We automate this in Windows 11 using a simple PowerShell script called from a batch script to generate desktop `.lnk` files pointing to `shutdown.exe` with arguments.

create_shutdown_shortcut.bat 
@echo off
chcp 65001 >nul
powershell -NoProfile -ExecutionPolicy Bypass -Command ^
    "$s = New-Object -ComObject WScript.Shell; " ^
    "$d = $s.SpecialFolders('Desktop'); " ^
    "$lnk = $s.CreateShortcut((Join-Path $d 'Shutdown.lnk')); " ^
    "$lnk.TargetPath = 'shutdown.exe'; " ^
    "$lnk.Arguments = '/s /t 0'; " ^
    "$lnk.IconLocation = 'shell32.dll,27'; " ^
    "$lnk.Save();"

4. Show Desktop Toggle Shortcut

Since Quick Launch is obsolete in Windows 11, we can create a desktop shortcut pointing to the Explorer shell command for toggling the desktop: shell:::{3080F90D-D7AD-11D9-BD98-0000947B0257}.

show_desktop_icon.bat 
@echo off
chcp 65001 >nul
powershell -NoProfile -ExecutionPolicy Bypass -Command ^
    "$s = New-Object -ComObject WScript.Shell; " ^
    "$d = $s.SpecialFolders('Desktop'); " ^
    "$lnk = $s.CreateShortcut((Join-Path $d 'Show Desktop.lnk')); " ^
    "$lnk.TargetPath = 'explorer.exe'; " ^
    "$lnk.Arguments = 'shell:::{3080F90D-D7AD-11D9-BD98-0000947B0257}'; " ^
    "$lnk.IconLocation = 'shell32.dll,34'; " ^
    "$lnk.Save();"
