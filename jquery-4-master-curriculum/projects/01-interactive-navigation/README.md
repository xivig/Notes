# 📱 Project 01: Interactive Responsive Navigation

An accessible, responsive multi-level navbar featuring mobile off-canvas drawer animations, outside-click dismissal, and keyboard accessibility.

---

### Features
- Responsive layout adapting smoothly from desktop horizontal bar to mobile vertical drawer.
- Multi-level dropdown menus toggled with slide animations.
- Outside-click dismissal using document-level event capturing.
- `Escape` key listener for accessible menu closure.
- Zero deprecated jQuery shortcuts — 100% strictly built on **jQuery 4.0.0**.

### How to Run
Open [`index.html`](index.html) directly in any web browser.
