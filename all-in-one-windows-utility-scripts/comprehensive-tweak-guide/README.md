# Windows 11 Customizations & Tweaks Handbook

This textbook contains systematic step-by-step documentation detailing registry modifications, folder security protections, USB restrictions, and Explorer shell hacks optimized for **Windows 11**.

---

## 📚 Curriculum Structure

This guide contains four detailed chapters:

1. **[Chapter 1: Windows 11 Registry Operations & Policies](./01_registry_tweaks.md)** ([Interactive HTML](./01_registry_tweaks.html))
   * Learn REG file version syntax, `WaitToKillServiceTimeout`, disabling CD/USB AutoPlay, and LegalNotice pre-login messages.
2. **[Chapter 2: USB Port Protections & Storage Security](./02_system_tweaks.md)** ([Interactive HTML](./02_system_tweaks.html))
   * Configure `StorageDevicePolicies` to force read-only USB writes, and block the `USBSTOR` service storage driver entirely.
3. **[Chapter 3: Windows Explorer & Shell Customizations](./03_explorer_tweaks.md)** ([Interactive HTML](./03_explorer_tweaks.html))
   * Lock folders using Control Panel CLSID string suffixes, disable the Start menu Run option box, create shutdown/restart desktop shortcuts, and generate Show Desktop icons.
4. **[Chapter 4: Special Windows 11 Utilities & Lists](./04_other_tricks.md)** ([Interactive HTML](./04_other_tricks.html))
   * Enable the built-in administrator account, generate directory file mapping indexes, disable Adobe auto-updates, spoof system processor strings, and reference keyboard shortcuts and diagnostic Run commands.
