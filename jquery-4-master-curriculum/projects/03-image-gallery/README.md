# 🖼️ Project 03: Image Gallery & Lightbox

A responsive photography gallery featuring thumbnail grids, full-screen overlay lightbox previews, circular image cycling, and keyboard accessibility.

---

### Features
- Responsive grid displaying low-resolution thumbnails with hover depth animations.
- Modal lightbox overlay displaying high-resolution imagery.
- Circular array cycling (`(index + length) % length`) for smooth infinite Next / Previous navigation.
- Full keyboard accessibility: Arrow Left (previous), Arrow Right (next), and Escape (dismiss).
- Outside backdrop click dismissal.

### How to Run
Open [`index.html`](index.html) in your browser.
