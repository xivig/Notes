Chapter 01 PHP Foundations, Zend Engine & Modern Tooling

Understand the Zend Engine execution lifecycle, OPcache & JIT, CLI vs PHP-FPM SAPIs, PER Coding Style 2.0, and file-level declare(strict_types=1).

  • Always open pure PHP files with <?php and omit the closing ?> tag to prevent accidental header corruption.
  • Place declare(strict_types=1); as the very first statement in every PHP file.
  • Use php -l for syntax linting, php --ini (or php --ini=diff in PHP 8.5+) for config inspection, and php -S only for local development.
Developer Best Practice: Keep display_errors = Off and log_errors = On in production php.ini so stack traces never leak to HTTP clients.

Chapter 02 Types, Variables, Constants & Strict Mode

Master PHP scalar, compound, and special types, strict_types=1 enforcement, == vs === behavior changes in PHP 8+, constants, and get_debug_type().

  • With strict_types=1, passing "42" to an int parameter throws TypeError immediately (only int -> float widening is allowed).
  • PHP 8.0 fixed 0 == "foobar" to false, yet strict === / !== remains the safest default everywhere.
  • Store money in integer minor units (cents/paise) or bcmath strings — never binary float.
Developer Best Practice: Use get_debug_type($var) (PHP 8.0+) instead of legacy gettype() for exact class names and canonical scalar names.

Chapter 03 Operators & Modern Control Flow

Replace fragile switch statements with strict, exhaustive match expressions (PHP 8.0+), and master ??, ??=, <=>, and safe foreach iteration.

  • match performs strict (===) comparison, never falls through, returns a value, and throws UnhandledMatchError if unmatched.
  • Null coalescing (??) and coalescing assignment (??=) safely provide defaults without undefined-key warnings.
  • Spaceship (<=>) returns -1, 0, or 1 for concise usort() comparators.
Developer Best Practice: If iterating by reference (foreach ($arr as &$v)), always unset($v) immediately afterward to avoid corrupting the last item.
chapters/03-operators-and-control-flow/lab.php
Open File ↗ 
<?php

declare(strict_types=1);

/**
 * Chapter 03 Lab: Operators, Null Coalescing, Spaceship & Match Expressions
 */

echo "=== Chapter 03: Operators & Control Flow ===" . PHP_EOL;

// 1. Null coalescing (??) and null coalescing assignment (??=)
$options = ['host' => '127.0.0.1'];
$port = $options['port'] ?? 3306;
$options['charset'] ??= 'utf8mb4';

echo "Host: {$options['host']}, Port: {$port}, Charset: {$options['charset']}" . PHP_EOL;

// 2. Spaceship operator (<=>)
$scores = [85, 92, 78, 95];
usort($scores, static fn (int $a, int $b): int => $b <=> $a);
echo "Sorted descending: " . implode(', ', $scores) . PHP_EOL;

// 3. Modern match expression (PHP 8.0+)
$resolveHttpMessage = static fn (int|string $statusCode): string => match ($statusCode) {
    200, 201 => 'OK / Created',
    400      => 'Bad Request',
    404      => 'Not Found',
    500      => 'Internal Server Error',
    '200'    => 'Strict string "200" (not integer 200)',
    default  => 'Other Status',
};

echo "Code 200 (int)   : " . $resolveHttpMessage(200) . PHP_EOL;
echo "Code '200' (str) : " . $resolveHttpMessage('200') . PHP_EOL;

// 4. Exhaustiveness check throwing UnhandledMatchError
try {
    $strictOnly = match (418) {
        200 => 'OK',
        404 => 'Missing',
    };
} catch (UnhandledMatchError $e) {
    echo "Caught UnhandledMatchError: " . $e->getMessage() . PHP_EOL;
}

Chapter 04 Functions, Closures, Callables & Generators

Write self-documenting APIs with Named Arguments (8.0), arrow functions, First-Class Callable syntax strlen(...) (8.1), never return type, and O(1)-memory Generators.

  • Named arguments allow skipping intermediate optional parameters and make boolean flags unambiguous.
  • First-Class Callables ($calc->add(...), trim(...)) create genuine Closure objects with static-analysis safety.
  • Generators (yield) stream massive datasets lazily without loading whole collections into RAM.
Developer Best Practice: Mark non-object closures static fn (...) => ... so PHP skips unnecessary $this scope binding.
chapters/04-functions-closures-and-callables/lab.php
Open File ↗ 
<?php

declare(strict_types=1);

/**
 * Chapter 04 Lab: Named Arguments, Closures, First-Class Callables & Generators
 */

class Calculator
{
    public function add(int $a, int $b): int
    {
        return $a + $b;
    }
}

function createOrderSummary(
    string $customer,
    float $subtotal,
    float $taxRate = 0.10,
    string $currency = 'USD',
): string {
    $total = $subtotal * (1 + $taxRate);
    return sprintf('%s: %s %.2f', $customer, $currency, $total);
}

function generateFibonacci(int $count): Generator
{
    $a = 0;
    $b = 1;
    for ($i = 0; $i < $count; $i++) {
        yield $a;
        [$a, $b] = [$b, $a + $b];
    }
}

echo "=== Chapter 04: Functions, Closures & Callables ===" . PHP_EOL;

// 1. Named arguments skipping default $taxRate
echo createOrderSummary(customer: 'Alice', subtotal: 100.0, currency: 'EUR') . PHP_EOL;

// 2. First-class callables (PHP 8.1+)
$lengthFn = strlen(...);
echo "Length of 'Modern PHP': " . $lengthFn('Modern PHP') . PHP_EOL;

$calc = new Calculator();
$adder = $calc->add(...);
echo "Calculator::add(15, 25) = " . $adder(15, 25) . PHP_EOL;

// Clean pipeline with first-class callable + arrow function
$rawNames = ['  alice ', ' BOB', 'charlie  '];
$cleaned = array_map(trim(...), $rawNames);
$upper = array_map(strtoupper(...), $cleaned);
echo "Normalized names: " . implode(', ', $upper) . PHP_EOL;

// 3. Generator lazy sequence
$fibs = iterator_to_array(generateFibonacci(8));
echo "First 8 Fibonacci numbers: " . implode(', ', $fibs) . PHP_EOL;

Chapter 05 Arrays & Functional Data Pipelines

Distinguish lists from associative maps using array_is_list() (8.1), master string-keyed unpacking, functional transforms, array_find (8.4), and array_first/last (8.5).

  • Re-index filtered lists with array_values() before json_encode() so PHP emits [] instead of {}.
  • Always pass strict=true as the 3rd argument to in_array($needle, $haystack, true).
  • PHP 8.4 added array_find(), array_find_key(), array_any(), array_all(); PHP 8.5 added array_first() and array_last().
Developer Best Practice: Use array_column($rows, null, "id") to turn O(N^2) nested loops into O(1) dictionary lookups.
chapters/05-arrays-and-functional-pipelines/lab.php
Open File ↗ 
<?php

declare(strict_types=1);

/**
 * Chapter 05 Lab: Arrays, Unpacking, Destructuring & Functional Pipelines
 */

echo "=== Chapter 05: Arrays & Functional Pipelines ===" . PHP_EOL;

$products = [
    ['id' => 1, 'name' => 'Mechanical Keyboard', 'price' => 120, 'active' => true],
    ['id' => 2, 'name' => 'Legacy Mouse',        'price' => 25,  'active' => false],
    ['id' => 3, 'name' => '4K Monitor',          'price' => 380, 'active' => true],
    ['id' => 4, 'name' => 'USB-C Hub',           'price' => 45,  'active' => true],
];

// 1. Filter -> Re-index -> Sort -> Map pipeline
$activeProducts = array_values(array_filter(
    $products,
    static fn (array $item): bool => $item['active']
));

usort($activeProducts, static fn (array $a, array $b): int => $a['price'] <=> $b['price']);

$labels = array_map(
    static fn (array $item): string => "{$item['name']} (\${$item['price']})",
    $activeProducts
);

echo "Active sorted products: " . implode(' | ', $labels) . PHP_EOL;

// 2. Total value using array_reduce
$totalActiveValue = array_reduce(
    $activeProducts,
    static fn (int $carry, array $item): int => $carry + $item['price'],
    0
);
echo "Total active catalog price: \${$totalActiveValue}" . PHP_EOL;

// 3. array_is_list() & JSON safety (PHP 8.1+)
$sparse = [0 => 'a', 2 => 'c'];
$dense  = array_values($sparse);
echo "Sparse is list? " . (array_is_list($sparse) ? 'yes' : 'no') . " -> " . json_encode($sparse) . PHP_EOL;
echo "Dense is list?  " . (array_is_list($dense) ? 'yes' : 'no') . " -> " . json_encode($dense) . PHP_EOL;

// 4. Associative array unpacking (PHP 8.1+) & indexing with array_column
$defaults = ['perPage' => 20, 'sort' => 'asc'];
$overrides = ['perPage' => 50];
$queryConfig = [...$defaults, ...$overrides];
echo "Query config: " . json_encode($queryConfig) . PHP_EOL;

$byId = array_column($products, 'name', 'id');
echo "Lookup ID 3: " . ($byId[3] ?? 'Unknown') . PHP_EOL;

Chapter 06 Strings, UTF-8 Multibyte, Regex & DateTimeImmutable

Use str_contains/str_starts_with/str_ends_with (8.0), mbstring UTF-8 helpers, PCRE named captures, and immutable UTC timestamps via DateTimeImmutable.

  • Prefer str_contains(), str_starts_with(), and str_ends_with() over error-prone strpos(...) !== false checks.
  • Always use mb_strlen() / mb_substr() for UTF-8 user strings instead of byte-based strlen()/substr().
  • Always store and calculate dates using DateTimeImmutable in UTC; convert timezones only at display time.
Developer Best Practice: Add the /u regex modifier when matching UTF-8 strings with preg_match() or preg_replace_callback().

Chapter 07 OOP Foundations, Instances & Inheritance

Model domains with strongly typed classes, distinct object instances, extends inheritance, explicit parent:: delegation, and safe method overriding.

  • Object variables hold handles referencing heap objects; assigning $b = $a aliases the same object unless cloned.
  • Overriding __construct() in a child class does not automatically call parent::__construct(); invoke it explicitly.
  • Keep inheritance shallow and favor composition + interfaces over multi-level class hierarchies.
Developer Best Practice: Type every class property explicitly so PHP guards against uninitialized or invalid state.
chapters/07-oop-foundations-and-inheritance/lab.php
Open File ↗ 
<?php

declare(strict_types=1);

/**
 * Chapter 07 Lab: Classes, Multiple Instances, Inheritance & Method Overriding
 */

class BaseComponent
{
    public string $title;

    public function __construct(string $title = 'Base Component')
    {
        $this->title = $title;
    }

    public function setTitle(string $title): void
    {
        $this->title = $title;
    }

    public function describe(): string
    {
        return "[" . static::class . "] Title: {$this->title}";
    }
}

class Widget extends BaseComponent
{
    private string $category;

    public function __construct(string $title, string $category)
    {
        // Explicitly invoke parent constructor
        parent::__construct($title);
        $this->category = $category;
    }

    public function describe(): string
    {
        // Delegate to parent method and extend output
        return parent::describe() . " (Category: {$this->category})";
    }
}

echo "=== Chapter 07: OOP Foundations & Inheritance ===" . PHP_EOL;

// 1. Multiple independent instances
$itemA = new BaseComponent('Header');
$itemB = new BaseComponent('Footer');
$itemB->setTitle('Updated Footer');

echo $itemA->describe() . PHP_EOL;
echo $itemB->describe() . PHP_EOL;

// 2. Inheritance & method overriding
$widget = new Widget('Analytics Chart', 'Dashboard');
echo $widget->describe() . PHP_EOL;

Chapter 08 Magic Methods & Object Lifecycle

Master __construct, __destruct, unset(), Stringable (__toString), __get/__set/__isset, __call/__callStatic, and deep copying via __clone().

  • Implementing __toString(): string automatically satisfies PHP 8.0+ Stringable type hints; omitting it throws Error on string cast.
  • Customizing __clone() ensures nested mutable dependencies are deep-copied and unique IDs regenerated.
  • Dynamic undeclared properties trigger deprecation notices in PHP 8.2+ (define explicit properties or __get/__set).
Developer Best Practice: Prefer __serialize() and __unserialize() over the legacy Serializable interface.
chapters/08-magic-methods-and-object-lifecycle/lab.php
Open File ↗ 
<?php

declare(strict_types=1);

/**
 * Chapter 08 Lab: Magic Methods, Object Lifecycle, Stringable & Deep Cloning
 */

class NonStringableBox
{
    public function __construct(public string $label) {}
}

class ResourceSession implements Stringable
{
    /** @var array<string, mixed> */
    private array $attributes = [];

    public function __construct(
        public string $sessionId,
        public NonStringableBox $box,
    ) {
        echo "  [__construct] Session {$this->sessionId} opened." . PHP_EOL;
    }

    public function __destruct()
    {
        echo "  [__destruct]  Session {$this->sessionId} closed." . PHP_EOL;
    }

    public function __toString(): string
    {
        return "Session({$this->sessionId}, box={$this->box->label})";
    }

    public function __get(string $name): mixed
    {
        return $this->attributes[$name] ?? null;
    }

    public function __set(string $name, mixed $value): void
    {
        $this->attributes[$name] = $value;
    }

    public function __isset(string $name): bool
    {
        return isset($this->attributes[$name]);
    }

    public function __call(string $name, array $arguments): string
    {
        return "__call intercepted {$name}(" . implode(', ', $arguments) . ")";
    }

    public static function __callStatic(string $name, array $arguments): string
    {
        return "__callStatic intercepted {$name}(" . implode(', ', $arguments) . ")";
    }

    public function __clone(): void
    {
        // Generate new ID and deep-clone nested mutable object
        $this->sessionId = uniqid('CLONE_', true);
        $this->box = clone $this->box;
    }
}

echo "=== Chapter 08: Magic Methods & Object Lifecycle ===" . PHP_EOL;

// 1. Attempting string conversion without __toString() throws Error in PHP 8+
$plain = new NonStringableBox('Alpha');
try {
    echo (string) $plain;
} catch (Error $e) {
    echo "Expected Error without __toString(): " . $e->getMessage() . PHP_EOL;
}

// 2. Construct, __toString / Stringable, __set / __get, __call / __callStatic
$session = new ResourceSession('SESS_001', $plain);
echo "Stringable output: {$session}" . PHP_EOL;

$session->theme = 'dark';
echo "Dynamic __get('theme'): " . ($session->theme ?? 'none') . PHP_EOL;
echo $session->dispatch('audit', 'user:42') . PHP_EOL;
echo ResourceSession::ping('healthcheck') . PHP_EOL;

// 3. Deep cloning via __clone()
$cloned = clone $session;
$cloned->box->label = 'Beta';
echo "Original box label : {$session->box->label}" . PHP_EOL;
echo "Cloned box label   : {$cloned->box->label}" . PHP_EOL;

// 4. Explicit destruction with unset()
unset($cloned, $session);
echo "End of Chapter 08 script." . PHP_EOL;

Chapter 09 Abstraction, Interfaces, Polymorphism & Traits

Design pluggable architectures using Interfaces, shared template base classes with abstract methods, polymorphic dependency injection, and Trait composition.

  • Program to interfaces (PaymentMethod) rather than concrete implementations (StripeGateway) to keep callers decoupled.
  • Abstract classes hold shared state + template logic; interfaces define pure behavioral contracts across unrelated classes.
  • Resolve Trait method collisions explicitly with insteadof and as aliases.
Developer Best Practice: Traits should supply small cohesive behaviors, not hide global dependencies or service state.
chapters/09-abstraction-polymorphism-and-traits/lab.php
Open File ↗ 
<?php

declare(strict_types=1);

/**
 * Chapter 09 Lab: Abstract Classes, Interfaces, Polymorphism & Traits
 */

trait TimestampedLog
{
    public function log(string $message): void
    {
        echo "[LOG " . date('H:i:s') . "] {$message}" . PHP_EOL;
    }
}

interface PaymentMethod
{
    public function pay(int $amountCents): string;
}

abstract class BasePaymentGateway implements PaymentMethod
{
    use TimestampedLog;

    public function __construct(protected string $merchantId) {}

    abstract protected function providerName(): string;

    public function receiptLine(int $amountCents): string
    {
        $dollars = number_format($amountCents / 100, 2);
        return "{$this->providerName()} (merchant={$this->merchantId}) charged \${$dollars}";
    }
}

final class CardGateway extends BasePaymentGateway
{
    public function pay(int $amountCents): string
    {
        $this->log("Authorizing card payment...");
        return $this->receiptLine($amountCents);
    }

    protected function providerName(): string
    {
        return 'CreditCard';
    }
}

final class UpiGateway extends BasePaymentGateway
{
    public function pay(int $amountCents): string
    {
        $this->log("Verifying instant UPI transfer...");
        return $this->receiptLine($amountCents);
    }

    protected function providerName(): string
    {
        return 'UPI';
    }
}

function processOrderPayment(PaymentMethod $method, int $amountCents): void
{
    echo "  -> " . $method->pay($amountCents) . PHP_EOL;
}

echo "=== Chapter 09: Abstraction, Polymorphism & Traits ===" . PHP_EOL;
processOrderPayment(new CardGateway('M_101'), 4999);
processOrderPayment(new UpiGateway('M_202'), 1500);

Chapter 10 Encapsulation, Final, Readonly & Late Static Binding

Enforce strict boundaries with visibility modifiers, final classes/methods, readonly properties (8.1) & readonly classes (8.2), and runtime Late Static Binding (static::).

  • final readonly class creates concise, immutable Value Objects and DTOs in PHP 8.2+.
  • readonly properties must always declare an explicit type and can only be initialized once.
  • static:: resolves the class invoked at runtime, whereas self:: binds to the parent class at compile time.
Developer Best Practice: Default service classes and DTOs to final unless deliberately architected as extension points.
chapters/10-encapsulation-immutability-and-lsb/lab.php
Open File ↗ 
<?php

declare(strict_types=1);

/**
 * Chapter 10 Lab: Encapsulation, Final, Readonly Classes & Late Static Binding
 */

// 1. Immutable Value Object using final readonly class (PHP 8.2+)
final readonly class AppConfig
{
    public function __construct(
        public string $env,
        public string $dbHost,
        public int $dbPort = 3306,
    ) {}
}

// 2. Encapsulation & final method
class Account
{
    private int $balanceCents = 0;

    public function __construct(
        public readonly string $accountId,

declare(strict_types=1);

/**
 * Chapter 17 Lab: PDO Prepared Statements, Allowlisted Sorting & Atomic Transactions (SQLite :memory:)
 */

final readonly class ProductRecord
{
    public function __construct(
        public int $id,
        public string $sku,
        public string $name,
        public int $priceCents,
    ) {}
}

final class ProductRepository
{
    public function __construct(private PDO $pdo) {}

    public function createSchema(): void
    {
        $this->pdo->exec(<<<SQL
            CREATE TABLE products (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                sku TEXT NOT NULL UNIQUE,
                name TEXT NOT NULL,
                price_cents INTEGER NOT NULL CHECK (price_cents >= 0)
            )
        SQL);
    }

    public function insert(string $sku, string $name, int $priceCents): int
    {
        $stmt = $this->pdo->prepare(
            'INSERT INTO products (sku, name, price_cents) VALUES (:sku, :name, :price)'
        );
        $stmt->execute([
            'sku'   => $sku,
            'name'  => $name,
            'price' => $priceCents,
        ]);
        return (int) $this->pdo->lastInsertId();
    }

    /** @return list<ProductRecord> */
    public function listSorted(string $sortColumn, string $direction = 'ASC'): array
    {
        // Strict allowlist for dynamic ORDER BY identifiers (never bind identifiers directly!)
        $column = match ($sortColumn) {
            'sku'   => 'sku',
            'name'  => 'name',
            'price' => 'price_cents',
            default => 'id',
        };
        $dir = strtoupper($direction) === 'DESC' ? 'DESC' : 'ASC';

        $stmt = $this->pdo->query("SELECT id, sku, name, price_cents FROM products ORDER BY {$column} {$dir}");
        $rows = $stmt->fetchAll();

        return array_map(
            static fn (array $r): ProductRecord => new ProductRecord(
                (int) $r['id'],
                (string) $r['sku'],
                (string) $r['name'],
                (int) $r['price_cents'],
            ),
            $rows
        );
    }
}

    echo "Rolled back failed transaction cleanly: " . $e->getMessage() . PHP_EOL;
}

foreach ($repo->listSorted('price', 'DESC') as $product) {
    $price = number_format($product->priceCents / 100, 2);
    echo "  - [{$product->sku}] {$product->name}: \${$price}" . PHP_EOL;
}

<?php

declare(strict_types=1);

/**
 * Chapter 18 Capstone Lab: Dependency Injection, WeakMap Caching, Mini Container & Self-Test Suite
 */

enum InvoiceStatus: string
{
    case Draft = 'draft';
    case Paid  = 'paid';
}

interface DiscountPolicy
{
    public function apply(int $amountCents): int;
}

final readonly class PercentageDiscount implements DiscountPolicy
{
    public function __construct(private int $percent)
    {
        if ($percent < 0 || $percent > 100) {
            throw new InvalidArgumentException('Discount percent must be 0..100.');
        }
    }

    public function apply(int $amountCents): int
    {
        return (int) round($amountCents * (100 - $this->percent) / 100);
    }
}

final class Invoice
{
    public function __construct(
        public readonly string $id,
        public readonly int $subtotalCents,
        public InvoiceStatus $status = InvoiceStatus::Draft,
    ) {}
}

final class PricingService
{
    /** @var WeakMap<Invoice, int> */
    private WeakMap $totalCache;

    public function __construct(private DiscountPolicy $discountPolicy)
    {
        $this->totalCache = new WeakMap();
    }

    public function calculateTotalCents(Invoice $invoice): int
    {
        // WeakMap memoizes per Invoice instance without preventing garbage collection
        return $this->totalCache[$invoice] ??= $this->discountPolicy->apply($invoice->subtotalCents);
    }
}

final class SimpleContainer
{
    /** @var array<string, callable(self): object> */
    private array $bindings = [];

    /** @param callable(self): object $factory */
    public function set(string $id, callable $factory): void
    {
        $this->bindings[$id] = $factory;
    }

    public function get(string $id): object
    {
        if (!isset($this->bindings[$id])) {
            throw new RuntimeException("Service not registered: {$id}");
        }
        return ($this->bindings[$id])($this);
    }
}

function assertSameValue(mixed $expected, mixed $actual, string $label): void
{
    if ($expected !== $actual) {
        throw new AssertionError("FAIL [{$label}]: expected " . var_export($expected, true) . ", got " . var_export($actual, true));
    }
    echo "  [TEST PASS] {$label}" . PHP_EOL;
}

echo "=== Chapter 18 Capstone: Architecture, WeakMap & Unit Verification ===" . PHP_EOL;

$container = new SimpleContainer();
$container->set(DiscountPolicy::class, static fn (): DiscountPolicy => new PercentageDiscount(20));
$container->set(
    PricingService::class,
    static fn (SimpleContainer $c): PricingService => new PricingService($c->get(DiscountPolicy::class))
);

/** @var PricingService $pricing */
$pricing = $container->get(PricingService::class);
$invoice = new Invoice('INV-2026-01', 10000);

assertSameValue(8000, $pricing->calculateTotalCents($invoice), '20% discount on 10000 cents');
assertSameValue(8000, $pricing->calculateTotalCents($invoice), 'WeakMap cache hit returns 8000');
assertSameValue(InvoiceStatus::Draft, $invoice->status, 'Default InvoiceStatus is Draft');

echo "All capstone assertions verified." . PHP_EOL;
