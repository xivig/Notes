Chapter 2

USB Port Protections & Storage Security

Secure Windows 11 against physical malware insertion and unauthorized data theft by restricting USB port behaviors, configuring write protection, and locking out storage drives.

1. Software USB Write Blocker (Read-Only Mode)

To prevent users or automated scripts from saving, deleting, or editing files on a connected USB flash drive, you can toggle write-protection in Windows 11. Creating a DWORD registry key named WriteProtect set to 1 forces all storage devices mounted to function in read-only mode.

usb_write_protect_enable.reg 
Windows Registry Editor Version 5.00

; Enable USB Write Protection (Makes USB storage devices read-only)
[HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\StorageDevicePolicies]
"WriteProtect"=dword:00000001

Note: Devices that are already mounted must be removed and re-inserted for this registry setting to take effect.

2. Disabling USB Storage Devices Entirely

If you want to disable all USB flash drives and external hard disks from functioning on a machine, you can change the startup mode of the Windows 11 USB storage driver (USBSTOR). Under the Services registry key, modifying the DWORD Start value to 4 blocks the driver from starting, rendering all flash storage devices completely inert when inserted.

usb_storage_disable.reg 
Windows Registry Editor Version 5.00

; Disable USB Storage Drives completely in Windows 11
[HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\USBSTOR]
"Start"=dword:00000004

To revert to default enabled operation, set the Start value back to 3.
